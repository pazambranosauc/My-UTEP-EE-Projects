# UTEP EE Projects: fundamentals and practice

My earlier hands-on work as an Electrical Engineering student at UTEP: the Arduino exercises I started on, small sensor projects, and KiCad and Fusion 360 practice. My main projects each have their own repository:

- **[esp32-devboard](https://github.com/pazambranosauc/esp32-devboard)**: custom ESP32 development board (KiCad)
- **[esp32-handheld-console](https://github.com/pazambranosauc/esp32-handheld-console)**: handheld game console (C, ESP-IDF)
- **[plc-traffic-light](https://github.com/pazambranosauc/plc-traffic-light)**: traffic light state machine (CODESYS, Ladder Diagram)
